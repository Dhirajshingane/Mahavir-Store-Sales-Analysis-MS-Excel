# 📊 Mahavir Store Sales Analysis 2022

## 📌 Project Overview

Mahavir Store Sales Analysis is an Excel-based data analytics project created to analyze and visualize sales performance, customer demographics, order status, sales channels, and state-wise sales for the year 2022.

The project uses an interactive Excel dashboard to convert raw sales data into meaningful business insights.

---

## 🎯 Project Objective

The main objective of this project is to analyze Mahavir Store's sales data and identify:

- Monthly sales and order trends
- Sales distribution between men and women
- Top-performing states
- Order status distribution
- Sales by different channels
- Customer age and gender distribution
- Overall sales performance

## 📊 Dashboard

The dashboard provides an interactive view of Mahavir Store's 2022 sales performance.

### Key Dashboard Components

- Sales vs Orders by Month
- Sales: Men vs Women
- Order Status
- Top 5 States by Sales
- Age vs Gender Analysis
- Channel vs Order Analysis
- Interactive Month, Channel and Category filters

---

## 📈 Key Analysis

### 1. Monthly Sales Analysis

Analyzed monthly sales and order performance to identify changes in sales throughout the year.

### 2. Gender Analysis

Compared sales contribution between male and female customers.

### 3. State-wise Sales

Identified the top-performing states based on sales.

### 4. Order Status Analysis

Analyzed delivered, cancelled, returned and refunded orders.

### 5. Channel Analysis

Compared orders across different sales channels such as:

- Amazon
- Myntra
- Flipkart
- Ajio
- Meesho
- Nalli
- Others

### 6. Age & Gender Analysis

Analyzed customer distribution across:

- Teenagers
- Adults
- Citizens

and compared male and female customers.
